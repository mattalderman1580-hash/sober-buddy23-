# Sober Buddy

A faith-based recovery companion. Built to sit with you in the hard moment — prayer, scripture, a 10-minute urge timer, and people who will pray with you.

Personal journal, story, triggers, and check-ins stay **on this device**. The Prayer Wall is a shared encouragement feed.

## What it does

- **Home console** — day count, status strip, quick actions
- **Urge mode** — “I’m thinking about using,” 10-minute timer, spoken prayer
- **Prayer Wall** — post a request, send encouragement, amen someone else’s post
- **People** — save contacts and text them a prayer or a word of encouragement
- **Your Story / Patterns / Goals** — the buddy uses what you enter
- **Journal + Log** — private notes and a technical timeline
- **Scripture library** — verses with speak-aloud
- **Slip processing** — learning, not shame
- **God First prayer flow** — write it, hear it spoken

## Run it locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal. On a phone, use **Add to Home Screen** / **Install app** so it feels like a native app.

## Privacy

- Your story, journal, check-ins, and people list are stored locally in the browser.
- Prayer Wall posts are shared (no accounts in this prototype). Do not put last names, addresses, or identifying details on the wall.
- If you are in crisis, call **988** (US) or **911**. This app is a companion, not a substitute for care.

## Stack

React, TanStack Start, Tailwind, Zustand, Postgres (prayer wall).
