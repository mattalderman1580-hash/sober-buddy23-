# Sober Buddy — project instructions

## Version history (mandatory)

Keep **every** update of this app. The user must be able to revert to any older version.

- Never delete, squash, amend, or force-push git history on `main`.
- Every shipped change is a new commit, pushed to GitHub: `mattalderman1580-hash/Sober-buddy`.
- Tag each shipped version (`v1-first-export`, `v2-dark-console`, `v3-light-theme`, `v4-github-sync`, …).
- To go back, restore that tag **without losing later commits** (revert commit or a restore branch). Do not reset `--hard` onto `main` in a way that drops history.
- Local uncommitted work is snapshotted before replacing the tree from GitHub.
